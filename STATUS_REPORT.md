## 📦 SPECTRUM OF TANGIBLE SOFTWARE GOODS & ASSETS

Work is categorized into three distinct layers according to the system taxonomy (`TAXONOMY.md`). Each layer produces modular, reusable, and sovereign software assets.

```
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│                               3-LAYER SYSTEM TAXONOMY                                   │
├─────────────────────────────────────────────────────────────────────────────────────────┤
│  @md (Domain Modules): AI Routers, Local Vector Stores, Speech Engines, Security        │
├─────────────────────────────────────────────────────────────────────────────────────────┤
│  @ux (User Experience & HCI): Ratatui/Neovim TUIs, PipeWire DSP, Azeron Hardware Keymaps│
├─────────────────────────────────────────────────────────────────────────────────────────┤
│  @rt (Runtime Substrate & @cmd): Nix Flakes, Zsh/Bash Toolchain, High-Performance CLIs │
└─────────────────────────────────────────────────────────────────────────────────────────┘
```

### 1. `@rt` — Runtime Substrate & Core Utility Assets
- **Declarative Nix Workstation Flakes**: Reproducible environment definitions anchoring CLI utilities (`ripgrep`, `fd`, `eza`, `fzf`, `gnupg`) across Linux, OpenBSD, and macOS without requiring full NixOS.
- **Core POSIX & Shell Modules**: Hardened shell scripts, s6 service supervision trees, and ZFS/VeraCrypt storage automation scripts.
- **Deterministic Build & Tooling Kits**: Standalone toolchains for LLVM IR code generation, static `musl libc` binary compilation, Rust, Haskell, OCaml, and C/C++ cross-compilation.

### 2. `@ux` — User Experience, HCI & Audio Assets
- **High-Density Modal TUIs**: Optimized Ratatui-based monitors and custom Neovim environments configured for modal editing and multi-file code synthesis.
- **Low-Latency Audio Routing Subsystem**: PipeWire DSP configurations for real-time spatial audio feedback, acoustic signal isolation, and speech input processing.
- **Hardware Ergonomic Mappings**: Custom chorded keybinding definitions and thumbstick input profiles for the Azeron keypad and macro peripherals.

### 3. `@md` — Domain Modules & Sovereign AI Engines
- **Zero-Cost Multi-Provider LLM Quota Router**: LiteLLM proxy configuration and key-rotation matrix load balancing across Groq, Cerebras, Google Gemini, OpenRouter, and Cloudflare Workers AI.
- **Embedded Sovereign RAG & Vector Memory**: Pre-configured local vector stores (LanceDB, Qdrant) and dense embedding pipelines (`bge-small-en-v1.5`, FastEmbed).
- **Assistive Speech-to-Intent Tools**: Speech processing pipelines integrating Groq Whisper API and offline Faster-Whisper models for terminal voice control.
