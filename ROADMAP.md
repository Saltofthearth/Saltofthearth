## 🎯 Detailed Milestones by Domain

### 1. 💻 3-Layer System Substrate (`@rt`, `@ux`, `@md`)

- [ ] **Milestone 1.1 (`@rt`) — Nix Declarative Substrate**:
  - Implement Nix Flakes for reproducible workstation environment across Linux, OpenBSD, and macOS.
  - Standardize `@cmd` userland tools (`ripgrep`, `fd`, `eza`, `fzf`, `bat`, `gnupg`).

- [ ] **Milestone 1.2 (`@ux`) — Multimodal Interface Engine**:
  - Unify Wayland window management (Sway/Hyprland) with modal editor configurations (Neovim/Ratatui).
  - Implement low-latency PipeWire DSP audio graph routing and Groq Whisper speech command integration.
  - Finalize custom Azeron keypad layout maps and thumbstick chorded macro profiles.

- [ ] **Milestone 1.3 (`@md`) — Autonomous & Sovereign Subsystems**:
  - Deploy local LiteLLM proxy container with auto-failover and key-pool rotation.
  - Implement local offline vector database indexing with LanceDB and DuckDB for repository context retrieval.

### 2. 🤖 Zero-Cost Sovereign AI Tooling Full Stack

- [ ] **Milestone 2.1 — Multi-Provider Router Standardization**:
  - Configure LiteLLM dynamic key pools for Groq, Cerebras, Google Gemini 2.0 Flash, and OpenRouter.
  - Add automatic HTTP 429 rate-limit failover triggers and latency-based routing.

- [ ] **Milestone 2.2 — Autonomous Agent Pipeline (Jules Integration)**:
  - Establish automated pre-commit verification loops with linting, formatting, and unit testing guardrails.
  - Optimize multi-turn deep planning workflows and context window management.

- [ ] **Milestone 2.3 — Local Offline Fallback**:
  - Deploy quantized local LLM runners (`ollama`/`llama.cpp` with `deepseek-r1` and `qwen2.5-coder`) for zero-leakage offline operation.
